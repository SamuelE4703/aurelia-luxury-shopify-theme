# AURELIA — Luxury Shopify Theme Demo

A custom Shopify Online Store 2.0 theme demo built for a premium fashion/luxury storefront.

## Highlights

- Minimal luxury-focused product pages
- Responsive mobile-first layout
- Collection grid with Shopify filters and sorting
- Predictive search-ready header
- Product image gallery
- Variant selection
- Cart drawer
- Subtle hover and reveal interactions
- Editorial hero section
- Featured collection section
- Shopify theme settings for colors, typography and layout
- Clean Liquid, CSS and JavaScript structure

## Shopify compatibility

Built for Shopify Online Store 2.0 using Liquid, JSON templates, CSS and vanilla JavaScript.

Reviews and payment gateways are intentionally handled through Shopify/apps rather than hard-coded into the theme. The theme provides the product-page structure where those services can be displayed.

## Demo purpose

This is a self-initiated portfolio/demo project showing Shopify theme development and customization. It is not a client project.
